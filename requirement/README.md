# requirement — เอกสารความต้องการ (ระดับธุรกิจ)

โฟลเดอร์นี้เก็บ **ความต้องการเชิงธุรกิจ** ของร้านขายหลังคาเหล็ก
เขียนในภาษาที่เจ้าของร้านอ่านแล้วยืนยันได้ว่า "งานจริงเป็นแบบนี้" — ยังไม่ลงรายละเอียดว่าระบบจะทำอย่างไร

```
requirement/
├─ Requirement.md   เอกสารหลัก (§16 กระบวนการธุรกิจ, §17 กฎธุรกิจที่ต้องเคาะ)
├─ mermaid/         แผนภาพแยกไฟล์ เปิด/แก้ได้ด้วย text editor
└─ bpmn/            กระบวนการธุรกิจแบบ BPMN 2.0 (ไฟล์เดียวครบทั้งกระบวนการ)
```

## ไฟล์ Mermaid

| ไฟล์ | อธิบาย |

| `02-order-lifecycle.mmd` | วงจรชีวิตของรายการขาย ตั้งแต่เริ่มจนปิดหรือยกเลิก |

| `05-activity-delivery.mmd` | B-2 กระบวนการจัดส่งสินค้า |
| `06-activity-stock-in.mmd` | B-3 กระบวนการรับสินค้าเข้าร้าน |

### วิธี render

```bash
# ทีละไฟล์
npx -y @mermaid-js/mermaid-cli -i mermaid/04-activity-sale.mmd -o 04-activity-sale.svg

# ทั้งโฟลเดอร์
for f in mermaid/*.mmd; do
  npx -y @mermaid-js/mermaid-cli -i "$f" -o "${f%.mmd}.svg"
done

# ออกเป็น PNG ความละเอียดสูงสำหรับใส่สไลด์
npx -y @mermaid-js/mermaid-cli -i mermaid/04-activity-sale.mmd -o sale.png -s 3
```

ดูเร็ว ๆ โดยไม่ต้องลงอะไร: วางเนื้อไฟล์ลงที่ <https://mermaid.live>
หรือใน VS Code ใช้ส่วนขยาย *Markdown Preview Mermaid Support* / *Mermaid Editor*

## ไฟล์ BPMN

`bpmn/business-process-sale-and-delivery.bpmn` — กระบวนการขายและส่งมอบสินค้าทั้งกระบวนการในไฟล์เดียว
แบ่งเป็น 4 lane: **ลูกค้า / พนักงานขาย / เจ้าของร้าน / พนักงานส่งของ** ครอบคลุมตั้งแต่ลูกค้าถามซื้อ
→ ตรวจของ → คิดราคา → ชำระเงิน → รับเองหรือจัดส่ง → ตรวจหลักฐาน → ปิดการขาย
รวมทางแยกกรณีของไม่พอ, ส่งไม่สำเร็จ, นัดส่งใหม่ และยกเลิกคืนเงิน

### วิธีเปิด / แก้

| วิธี | ขั้นตอน |
|------|--------|
| เว็บ (ง่ายสุด) | เปิด <https://demo.bpmn.io> แล้วลากไฟล์ `.bpmn` วางลงไป แก้แล้วกด download ได้เลย |
| โปรแกรม | ติดตั้ง [Camunda Modeler](https://camunda.com/download/modeler/) → File → Open |
| แปลงเป็นรูป | `npx -y bpmn-to-image --no-footer bpmn/business-process-sale-and-delivery.bpmn:process.png` |

ไฟล์มีพิกัดตำแหน่ง (BPMN DI) ฝังมาแล้ว เปิดปุ๊บเห็นผังทันที ไม่ต้องจัดวางเอง
ถ้าอยากขยับกล่องให้สวยขึ้น แก้ใน Camunda Modeler แล้ว save ทับได้
